Sube un archivo .json con una lista de productos y servicios. Cada registro se crea como uno nuevo en el catálogo.

Formato del archivo
[
  { "nombre": "Batería para máquina", "categoria": "Producto", "precio": 85000 },
  { "nombre": "Mantenimiento general", "categoria": "Servicio", "precio": 35000 }
]

Obligatorio: nombre. Opcionales: categoria (Producto o Servicio), precio y codigo. Si un registro no trae código, el sistema le asigna el siguiente consecutivo. Si no dice "Servicio", se registra como producto.
